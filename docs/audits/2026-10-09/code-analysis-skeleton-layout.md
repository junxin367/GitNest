# 代码分析骨架与页面布局对齐

## 检查结果

- 模块懒加载使用 App 内的通用模板，数据读取使用页面内的另一套模板。前者缺少五张摘要卡片，图区域结构也不同。
- 页面模板复制了标题、分栏、卡片和响应式规则，图标题误用横排，重新分析按钮占位为 96px，而实际按钮宽 112px。
- 图内缩放工具栏和底部操作说明缺少占位，全屏按钮被画成圆形，实际为圆角方形。
- 图中固定的七个占位节点与数据决定的实际图结构没有对应关系；运行状态固定五个标签也不能代表实际 Language Server 和提示数量。
- 窄窗口的占位列表参与固有高度计算，在验证中将左栏撑至 499.5px，关系图比实际最小 420px 左栏下移 79.5px。

## 修复

- 抽出轻量 `CodeAnalysisSkeleton`，App 懒加载与页面首次数据读取共用模板。实际分析页面仍按需加载。
- 复用真实标题、摘要卡片、工作区、导航、关系图标题及响应式 CSS，删除重复布局和旧 App 图骨架样式。
- 对齐固定按钮和双行图标题，补齐图内工具栏和操作说明占位；固定说明用真实文本度量宽度，文字透明且所在区域对辅助技术隐藏。
- 图数据用中性画布占位，不再预设节点数量和排列。运行栏只预留确定存在的分析时间与耗时。
- 导航占位行在已分配的列表区域内裁剪，不再撑高窄窗口左栏。

## 验证

- 现有导航、页面、分析 Hook 和公共 UI 测试共 90 条通过。
- 桌面主进程/渲染器类型检查、生产构建及架构边界检查通过。
- 使用实际组件生成的 DOM 和生产 CSS，在 Electron 中检查 1280、980、640px 宽度。每个宽度包含首次加载、请求链结果、代码节点结果，共九组，无页面横向溢出。
- 请求链结果与骨架的标题区、摘要、运行栏、工作区、左右面板、导航头、页签、图标题外框、图操作区、画布、缩放控件及底部说明外框位置和尺寸一致。顶部 LSP 按钮文字度量带来约 0.03px 亚像素差异；可变图副标题占位宽度不作为固定锚点比较。
- 查看宽屏骨架、真实请求链及窄屏截图。几何记录与截图位于 `temp/analysis-skeleton-20261009/`；临时导出测试代码和 Electron 验证脚本已删除。

此验证使用受控结果 DOM 的 Electron 渲染，不是完整应用真实 IPC 时序验证。首次读取前未知的请求链/代码节点模式、LSP 状态、提示、空结果及图拓扑不能预先一一匹配；这次对齐的是固定布局。已加载内容返回页面的保留逻辑不变。未生成安装包、未提交代码。
