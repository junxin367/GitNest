# 代码分析布局稳定性检查

检查范围：代码分析页的刷新、节点详情、源码抽屉、关系图，以及共用 Diff 查看器中的行定位和搜索。

## 已修复

- 有结果时重新分析：进度面板原本插在摘要上方，导致工作区整体下移。现在进度与运行状态栏使用同一个布局位置；状态栏保留占位并在进度显示时隐藏。
- 操作按钮：取消分析按钮与开始/重新分析按钮统一为 112px，切换状态不再改变操作区宽度。
- 行定位和搜索：源码与 Diff 使用限定内容区的滚动方法，支持 split Diff 内部的横向、纵向容器，不再滚动查看器外的页面。
- 关系图：同一工作区、分析范围、焦点及图结构下，刷新分析版本保留缩放、平移和节点拖动位置。
- 节点详情：新的节点预览暂时缺少当前节点时，保留已经打开的详情和抽屉，直到节点查询返回；完整查询结果仍决定节点是否存在。
- 源码加载：骨架屏立即显示，消除默认延迟造成的短暂空白。
