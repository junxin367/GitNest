# 隔离工程分析

本次替代同日 `analysis-project-write-boundary.md` 中的临时导入禁用方案。
生产入口的外部语言服务统一通过独立工程副本启动；隔离失败时保留内置分析并报告原因，
不会回退到原工程目录启动语言服务。

## 副本和结果

- 复制实际工作目录，包含未提交和未跟踪文件、构建配置、现有生成源码。
  不使用 Git checkout、硬链接或目录联接；不复制 `.git` 管理数据。
- 保留所选根目录之间的相对位置，补齐工作区范围内的祖先构建配置。
  已读取源码覆盖到副本，使语言服务和内置解析器使用相同文本。
- 同一次分析的语言服务共用副本，依次运行；每次分析创建新副本和新 JDT 索引，
  避免删除、重命名源码后沿用旧生成输出。依赖下载缓存保留在应用运行目录中。
- 只转换 LSP 的文件 URI 和路径字段；源码、文档和 opaque `data` 原样往返。
  调用关系、引用、类型关系和跳转位置映射回原工程。
- Java 在副本中开启自动构建以及 Maven/Gradle 导入，继续加载 Lombok agent。
  Rust 在副本中允许构建脚本和过程宏；Go 允许更新副本内模块文件；
  Kotlin/C# 不再被导入禁用策略提前阻止。
- 策略版本更新为 2，旧分析缓存不会被当作当前策略的完整结果。

## Windows 写入边界

启动器由嵌入的 C# 源码编译到应用专用目录，按源码摘要复用。
编译器为 Windows .NET Framework 自带的 `csc.exe`，不要求额外安装 SDK。

新隔离目录在复制任何源码或 Maven 配置前设置为当前账户与 SYSTEM 可访问，
并设置可继承的 Low integrity 标签。文件通过独立读写流复制，继承副本权限。
复用缓存时只检查权限和标签，禁止递归重新设置已有文件的 ACL/MIC：
构建工具可能创建硬链接，重新设置会影响硬链接对应的原文件。

启动语言服务前检查原目录及其父目录、所有现有子项的完整性标签。
原对象必须具有高于 Low 的禁止向上写入边界；未标记对象按 Windows 的 Medium 规则处理。
不修改原目录权限。无法查询、发现链接或发现 Low/Untrusted 原对象时拒绝启动。

语言服务使用 Low integrity 受限令牌，移除非必要特权。子进程继承该写入边界。
通过先挂起创建、分配 Job Object、再恢复的顺序启动；不允许脱离作业。
关闭启动器或分析进程退出时，整个构建进程树被终止。
普通退出、失败和取消都会先关闭语言服务，再删除当次副本。
应用异常退出可能留下副本目录，后续分析不会复用这些副本。

这层机制针对构建工具直接写回原文件的风险，不是用于运行恶意程序的完整安全沙箱。
网络和读取依赖仍可用。原项目的绝对输出路径不会被任意改写；
如果构建坚持写入原目录，该操作会失败并可能造成部分语义结果。

## 分批补全

全工程分析把文档数量和语义请求预算作为批次大小，持续处理后续批次，
而不是只保留前一批。仍限制并发，每批报告进度并让出事件循环处理取消。
变更分析保留单轮上限；预算为 0 仍表示禁用该类请求。

单文件符号、单符号引用、源码发现及图规模仍有数量限制。
超限、请求失败、缺失能力、工程导入错误或错误级源码诊断仍标记为部分结果。
分批完成不代表能够覆盖反射等全部运行时调用。

## 验证

- 真实 JDT LS 导入含 `lib`、`app` 两个模块的 Maven 工程副本，
  解析跨模块调用以及 Lombok 生成的 getter。
- 每批仅允许 1 个文件、1 个语义请求，仍完成两个文件及后续语义请求。
- 第二轮在原测试工程修改、重命名源码后重新分析，返回新符号，
  旧文件不再出现在结果中。
- 每轮前后比较原工程完整目录清单、所有文件 SHA-256 和修改时间，
  包括已有 `target/classes` 哨兵文件。
- 原生回归验证父进程、构建子进程写原文件被拒绝，副本可写，
  Low 原目录拒绝启动、目录重叠与联接拒绝、取消终止 detached 子进程。
  缓存中放置指向原文件的硬链接，验证启动器不会把它重新标记为可写。
- 全量 137 个测试文件、2217 项测试通过；收尾的 59 项语言服务回归及
  1 项真实 JDT 双轮验证再次通过。真实 JDT 验证程序按临时测试规则移除。
  全项目类型检查、架构检查和生产构建通过。

当前隔离实现适用于 Windows。含符号链接或目录联接的工程、
超过 250000 个文件或 4 GiB 的副本、无法确认写入保护的文件系统，
都会明确降级而不启动外部语言服务。
本次未执行真实 Gradle、Rust、Go、Kotlin 或 C# 工程验收。
首次隔离分析需要建立新索引并可能下载依赖，耗时会高于复用旧语言服务会话。
