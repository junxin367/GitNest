## 显示规则

| 当前状态 | 显示方式 |
| --- | --- |
| 当前目标尚无可用数据，正在读取 | 立即保留对应布局，等待 180ms 后渐入骨架 |
| 当前目标已有数据，后台刷新 | 保留内容 |
| 已成功读取空结果，后台刷新 | 保留空态 |
| 请求结束且结果为空 | 立即显示空态 |
| 首次读取失败 | 显示错误与重试入口 |
| 仓库、工作区或选择目标变化 | 不复用不属于当前目标的数据 |

共享组件按 `loading && !hasContent` 判断是否需要占位，视觉展示另由 `SkeletonSurface` 延迟控制，不在请求完成后强制延长骨架时间。已加载空数组与尚未加载分开处理。设置、分析、分支、历史、stash、工作区侧栏和全局搜索补充了相应状态处理。分析状态已到达但快照仍在读取时，加载状态继续有效。

## 第四轮：快速加载的展示时序

快速数据切换原先会立即挂载并显示骨架，即使请求只持续几十毫秒也会出现一次明显闪烁。本轮将加载状态与骨架的可见状态分开：

- 立即挂载布局占位，前 180ms 隐藏整个骨架区域，保持尺寸；不提前挂载空态、错误或旧目标内容。
- 超过等待窗口后，按现有 `--motion-micro`（180ms）渐入；扫光动画额外等待 420ms，隐藏期间暂停。
- 当前目标已有内容时继续保留内容；成功、空结果、错误或取消请求后立即解除占位，不使用最低可见时长拖延结果。
- 嵌套占位共享可见状态，只建立一个定时器、一个状态播报；连续等待沿用当前时钟，已完成后再次加载重新计时。卸载及 StrictMode 重挂载会清理计时器。
- 等待阶段不进入可访问性树，不触发加载播报。减少动态效果时取消渐入和扫光，但保留抗闪等待。
- Diff 内容、储藏列表/详情/文件、Workspace 简介和节点代码预览统一接入；同步修正包装层的宽度选择器和源码区域背景色。
- 修复变更文件列表在加载中且存在筛选词时误显示“没有匹配的变更”。

- 新增 7 条行为回归用例，覆盖快请求、慢请求、再次加载、连续换目标、嵌套计时/播报、StrictMode 清理和筛选空态。全量 119 个测试文件、1727 条测试通过。
- 桌面类型检查、架构边界、生产构建、`git diff --check` 通过；Electron 主流程（启动、扫描、仓库切换、监听刷新、搜索 Diff、重启恢复）通过。

## 第六轮：按实际页面布局自动生成

检查结果：此前只有手写模板和按视图选择模板，不具备 DOM 自动识别能力。本轮增加 `collectSkeletonLayout` 与 `AutoSkeletonBoundary`；`SkeletonBoundary` 省略 `fallback` 时启用自动模式。

自动模式保留真实子树的一次挂载，在首次读取期间设置 `inert`、`aria-hidden` 和透明度 0，读取其实际几何位置并生成覆盖层。数据完成后立即移除覆盖层、恢复交互，不重挂载输入和业务组件；已有内容后台刷新仍保留原内容。180ms 抗闪等待、共享展示时钟和减少动态效果规则继续有效。

识别与更新范围：

- 文本使用真实 Range 行片段生成逐行占位；按钮、输入框、选择器、SVG、图片、媒体与带相应 role 的控件作为整体识别，避免内部重复。
- 识别圆形头像和单选框、带边框的卡片，保留实际 Grid/Flex 布局与圆角。隐藏和显式忽略的节点不生成占位。
- 监听 DOM/尺寸变化、窗口缩放、字体与资源加载、内部及祖先滚动，以及 CSS 动画/过渡结束。更新合并到动画帧，加载结束或卸载后清理观察器和事件。
- 按滚动容器、祖先裁剪区与视口裁剪；局部可见的圆形、圆角和边框保持原始尺寸，只裁剪外层，不压缩变形。
- 每次最多遍历 2000 个元素、生成 600 个形状。结果只保存类型和几何信息，不保存文本、输入值、URL 或 HTML。

设置页已删除固定“4 个导航项、3 张卡片”的手写骨架，通用、AI、代码分析、Git、账号分区均使用真实布局自动生成。首次失败仍显示重试，后台刷新不遮挡已加载设置；首次读取前推迟 MCP 注册查询及 portal 提示。完整应用测试另外发现迟到的启动导航会覆盖用户已打开的设置页，已让 `navigate()` 中的主动导航优先于启动配置，确保加载后留在用户选择的页面。

### 接入方式与边界

```tsx
<SkeletonBoundary
  loading={loading}
  hasContent={loaded}
  label="正在读取页面"
>
  <PageContent data={data ?? initialValues} />
</SkeletonBoundary>
```

调用方在首次加载期间也必须提供真实页面结构。全高页面需让边界和 `.gn-auto-skeleton-content` 承接容器高度；设置页已配置。可用 `data-skeleton="ignore"` 排除区域，或用 `block`、`circle`、`text` 提示特殊元素的形状。仍传入 `fallback` 时沿用原手写模式。

这不是从页面名称猜测尚未渲染的内容：懒加载模块、条件分支中没有挂载的元素和虚拟列表未渲染的行无法识别，应继续提供备用模板。Canvas/iframe 只识别外框，伪元素与复杂图形内部不作语义识别。子组件的副作用和 portal 仍由调用方控制，不能仅依赖边界透明度屏蔽。
