# 交互延迟深入检查与优化

本轮覆盖 Diff、列表与搜索、代码图、设置与自动骨架、后台分析、Git 查询及实际页面接线。先保留修改前构建和差异，再对照真实 Electron 渲染、真实 Git 调用与确定性工作量。之前的骨架布局和安装器改动保留，未提交代码。

## 逐项检查矩阵

| 检查点 | 本轮处理与结论 |
| --- | --- |
| 长 Diff 下一搜索命中 | 当前命中样式局部更新，不再让全部代码行参与渲染；覆盖重复命中、内容替换与空态 |
| Diff 上下变更块导航 | 当前 hunk 状态与静态代码树分开；原导航、滚动和上下文功能保留 |
| 长 Diff 搜索输入与关闭 | 输入状态先响应，全文高亮延后；处理中禁止 Enter/F3 跳转旧结果，完成后发布正确数量 |
| Diff 浏览器重绘 | Trace 发现 React 工作下降后仍有大量绘制成本；代码行使用 paint containment，真实长行、换行、选择与横向滚动复核通过 |
| Diff 父层更新、右键菜单 | 行和单元格复用；同内容父更新、命中/hunk导航和右键不再读取全部正文或重新解析 |
| 文件列表与文件树选择 | 仅更新旧、新选中行；列表、树、键盘与动作目标回归保留 |
| 提交信息每键输入的实际接线 | 独立复核发现父级内联回调使行缓存失效；稳定 RepositoryChanges 的选择、权限、暂存/撤销/丢弃及上下文回调 |
| 独立 Diff 实际接线 | 同样稳定选择和文件操作回调；保留请求作用域与过期结果处理 |
| Sidebar 选择与菜单 | 行隔离、稳定菜单回调、按目标 ID 值传参；后台 IPC 克隆对象不再使所有行失效 |
| App 导航与选仓回调 | 稳定回调，选仓依赖目标 ID 值；真正切换目标时仍更新闭包，异步导航归属检查保留 |
| 全局搜索仓库候选构建 | 三类记录从逐目标线性查找改为首次匹配 Map，保持重复 ID 原语义 |
| 全局搜索连续输入 | 候选文本懒归一化并按内部结果对象缓存；空查询和结果上限不会主动规范化全部候选 |
| 全局搜索后台数据更新 | 前轮已有关闭时停查、16ms 结果合并；本轮仍保留完整候选重建/排序成本，不算已解决 |
| 历史提交选择与详情加载 | 筛选结果复用、行隔离；只格式化发生变化的历史行 |
| 历史追加与深页 | 追加记录保留已有行；列表仍全量 DOM，Git `--skip` 深分页与 HEAD 探测仍存在 |
| 图平移、缩放与选择 | 节点、边内容与画布状态分离；选择只更新前后节点，鼠标锚点、居中和重置语义保留 |
| 单节点拖动 | 最新位置通过 ref 读取，连接线正确联动；移动节点仍更新最多 320 条可见边，未声称所有布局成本消失 |
| 请求链搜索与方法筛选 | 节点 Map 和链文本随页面快照复用，空查询不建索引；公共一次性函数仍读取可变输入 |
| 源码抽屉下一命中 | 行级更新，500 行用例只重建前后命中的两行；首次着色、全文搜索和全量 DOM 仍有成本 |
| 图首次索引、布局及大结果传输 | 已有规模上限和快照索引保留；首次索引、完整结果 IPC/校验/持久化没有被本轮消除 |
| 后台分析逐文件进度 | utility 发送边界按同阶段 100ms 合并；阶段切换、完成立即发送，尾定时器确保后续慢任务不拖住已完成进度 |
| 分析取消、失败与完成 | 不补发取消后的旧进度；成功/失败前处理 pending，结束清理 timer，测试覆盖 |
| 自动骨架重复尺寸订阅 | 属性/文本变更只测量，不断开并重注册全部观察目标；结构改变时仅增删实际目标 |
| 自动骨架无变化更新 | 比较几何结果后再 dispatch；无变化不触发 React commit，真实尺寸变化仍更新 |
| 设置输入与后台刷新 | 输入已有本地草稿和显式保存；memo 设置 controller/页面隔离无关更新，真实应用刷新后草稿保留 |
| Workspace 全 DTO 引用共享 | 曾实现并测量；在最终列表优化后没有稳定额外收益且有深比较成本，已撤回，没有为了优化项数量保留 |
| 选仓与后台重扫争用 | 前轮已将扫描移出配置队列；本轮复核串行保存/代次校验仍必要，不删除正确性保护 |
| Git 调度与取消 | interactive 专用槽、共享槽、后台优先级及队列取消保留；没有提升所有后台任务优先级 |
| Snapshot upstream 与文件统计 | 独立查询并发，去掉一层串行等待；Git 命令数和状态校验保持 |
| 未跟踪大文件行数统计 | Buffer 逐字节迭代器改索引循环；64KiB 分块、二进制检测、末行和取消语义不变 |
| 分支比较历史 | 两个 exact ref 校验并发；实测时间没有改善，不把结构改变写成已量化提速 |
| Changes、后台快照与 Diff 的重复读取 | 需求和版本约束不同，本轮未加路径 TTL 或未经失效验证的共享缓存 |
| Stash、提交详情与分支列表 | 依赖 ref/hash、父提交和是否有远端的串行操作保持；未盲目并发增加无用 Git 工作 |
| 媒体 Diff | 大媒体完整读取、复制和 IPC 载荷仍存在，按需预览需要独立协议与生命周期改动 |
| 终端/编辑器检测、设置 API key 状态读取 | 切作用域可能重复检测，设置广播也可能重新读取 key 状态；已记录待量化项，未用不可靠缓存隐藏配置变化 |
| 大列表首次挂载、隐藏 Sidebar | 历史、文件和侧栏仍保留全部 DOM，隐藏/部分折叠主体仍存在；本轮未做窗口化 |

各分工进一步记录了触发条件、源码路径和未改原因，见证据目录中的 `diff/findings.md`、`lists/findings.md`、`graph/findings.md`、`app/findings.md`、`backend/findings.md`。没有把静态复杂度判断全部称为已测得的用户延迟。

## 正式对照结果

下列各组指标口径不同，不能相加，也不能把同步 CPU 时间当作操作系统输入到屏幕显示时间。

### Diff：真实 Electron 键鼠

生产组件与 CSS，冻结前后构建，2 轮交替；4,000/12,000 行、统一/并排不换行/并排换行，合计 312 次动作。导航每版本每场景 10 样本，输入与关闭各 2 样本。下面是 12,000 行中位数，单位 ms：

| 布局 | 输入首次反馈前→后 | 下一命中前→后 | 下一变更前→后 |
| --- | --- | --- | --- |
| 统一、不换行 | 490.60 → 23.45 | 72.55 → 26.20 | 89.10 → 46.15 |
| 并排、不换行 | 924.40 → 85.45 | 223.25 → 91.75 | 212.85 → 129.90 |
| 并排、换行 | 486.80 → 20.35 | 90.65 → 23.45 | 82.20 → 37.45 |

指标是捕获真实输入事件至第二次 requestAnimationFrame 的绘制机会近似值，不是物理屏幕延迟。输入列只表示首次反馈，完整高亮另行等待并验证。并排不换行的导航仍约 130ms、关闭仍约 157ms，大 DOM 和浏览器绘制是明确的剩余瓶颈。

四种换行/布局组合的额外验证中，所测锚点和滚动尺寸前后差值 0px，没有长行或多行文本裁剪；选取 239 字符成功；并排两侧和底部水平滚动都准确同步至 920px。未通过减少显示内容或关闭功能取得上述数字。

### 列表与搜索：真实 Electron 渲染

生产组件和 CSS、受控数据与回调，4 轮交替；每场景每版本 44 个正式样本，剔除每轮首个 warmup：

| 场景 | 事件→选中 DOM 更新前→后 |
| --- | --- |
| 1,000 条历史 | 4.8 → 1.1ms |
| 1,000 文件列表 | 15.0 → 1.6ms |
| 1,000 文件树 | 19.8 → 2.0ms |
| 500 仓库侧栏 | 5.7 → 1.4ms |

文件树事件至双帧的中位从 45.9 降至 33.3ms；其他场景仍约 33ms。10,000 文件连续不匹配查询同步 dispatch 从 3.4 降至 1.5ms。首个低命中查询仍需扫描候选，缓存主要减少后续重复准备工作。

实际父组件回归独立验证了接线：保留新文件行 memo、换回旧 RepositoryChanges，提交输入仍渲染 100 行；稳定真实回调后变为 0 行。不是仅在性能夹具中传固定 noop 来制造收益。

### 代码图、后台任务与骨架

- 图组件生产 React + Electron，160 节点，3 轮交替：滚轮派发和同步提交 1.6 → 0.5ms，选择 1.4 → 0.4ms。未包含完整应用 IPC、绘制排队或启动。
- 5,000 请求链热查询的规范化调用 5,001 → 1；500 行源码下一命中重建行数 500 → 2。
- 两阶段各 0–1,000 的分析进度突发，跨进程消息 2,002 → 4；持续阶段的最后更新仍由 100ms 尾定时器发出。
- 骨架 500 行、20 次属性通知：额外尺寸订阅 20,040 → 0、disconnect 20 → 0；真实宽度 220 → 280px 的变化仍正确同步。

上述调用次数是确定性工作量证据，不是完整 UI 毫秒数。`app/electron-results.json` 中结构共享方案的背景/侧栏计时属于已撤回探索，不能引用为最终收益；骨架验证对应保留实现。

同一真实仓库、同进程、前后各 7 次交替；每对输出深比较一致，仅排除实时 `refreshedAt`：

| 查询 | 修改前中位 | 修改后中位 | Git 进程数 |
| --- | --- | --- | --- |
