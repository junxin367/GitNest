# 展开、收起与局部面板交互优化

日期：2026-10-06，Asia/Shanghai。本轮接续仓库目录开合修复，检查类似交互是否触发无关列表计算、重挂载或全量布局。保留工作区已有修改，没有提交或生成安装包。

## 本轮实施

| 场景 | 原因与处理 | 保持的行为 |
| --- | --- | --- |
| 长仓库侧栏展开、隐藏恢复 | 前轮已经复用 DOM，但显示时仍布局全部行。超过 50 行时按 25 行组成布局块，使用 `content-visibility: auto` 延后处理屏幕外内容。 | 全部行仍在 DOM；原生键盘、查找、筛选、状态刷新、选中标记保留。小列表保持原结构。 |
| 文件树单目录开合 | 原来目录 Set 变化导致重建所有展开分区的文件和目录元素。改为按目录键订阅折叠值，分支和分区分别 memo。 | 收起的子树仍卸载，避免无界 DOM 保留；重新展开读取最新数据及折叠状态。 |
| 文件树分区开合、全部开合 | 分区更新不再重建其他分区；全局订阅仍更新“全部收起/展开”的汇总状态。 | 暂存/未暂存权限、右键、选择、搜索、显式 reveal、scope 切换和持久化偏好保留。 |
| Workspace 仓库状态、最近提交分区 | 折叠状态原在整页，开关任一分区重跑全部仓库 JSX。状态下沉到分区壳，children 和 DOM 保持。 | 隐藏时继续接收 snapshot、分支、HEAD、选择及回调更新。 |
| 概览相同属性的父层更新 | 页面增加默认浅比较 memo，跳过侧栏/检查器开关引起的相同属性更新。 | 没有自定义忽略字段的比较器；真实数据和回调改变仍更新。 |
| 分支创建面板、输入、行菜单及重命名 | 原来局部状态让全部分支行重新渲染，每行创建日期格式器。提取 memo 行、稳定菜单回调，编辑回调只传给当前行，日期按 `updatedAt` 缓存。 | 当前分支状态、busy、权限、菜单焦点、最新草稿、目标切换和数据替换保留。 |

本轮没有将前次的即时折叠、后台保存、失败回退、根高度动画移除等重复算作新成果。侧栏本轮 before 已包含这些修复。

## 复核发现并修正的边界

- 按位置分块可能在后台刷新删除前方行、或跨越 50 行阈值时重挂载当前焦点行。新增无额外 DOM 的提交边界：在 DOM 更新前记录实际组内焦点，更新后只在旧节点已移除、焦点回到 body、窗口有焦点、分组可见且相同 repository/worktree 仍存在时恢复。不会恢复已删除目标，也不会从搜索框、菜单、其他窗口抢焦点。
- 文件树已知目录集合与外部 store 的 Set 曾共享引用。全部收起后的新目录会先修改旧 snapshot，导致按键订阅无法识别变化。初始化改用独立 Set，所有后续 store 写入均复制后更新；新增受控偏好回归通过。
- 独立只读复核核对了外部 store 订阅清理、scope/reveal、隐藏数据更新、分支回调/日期及焦点修复。对焦点另外运行八个轻量场景，未发现剩余确认问题。

## 保留的成本和取舍

- 侧栏分块保留全部 DOM，未降低全部 DOM 的内存占用；首次挂载和真实列表更新仍有成本。未访问块使用行高估算，字号变大后滚动高度可能暂用估算，随着块进入视区更新；并未承诺动态字号变化时滚动条长度始终固定。
- 文件树数千行的全局浏览器布局仍明显；整分区展开仍需挂载其真实文件行。本轮没有将同步提交提速解释为全部屏幕卡顿消失。
- 概览 1,000 行展开布局 60.7→58.8ms，没有稳定布局收益；整页初次挂载和真实数据刷新继续执行。
- 分支首次挂载仍格式化全部日期，没有扩展系统 locale/时区缓存的生命周期。
- Worktrees 面板局部更新仍有多次统计及卡片渲染，未取得本轮独立性能证据，保留后续处理。
- 源码/差异抽屉重开涉及读取新鲜度，没有通过无限保存旧内容来减少读取。设置小分区和菜单定位缺少显著收益证据，未盲目重构。
